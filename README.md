## Selected research software

### [ORBEX-A](https://github.com/aaronjs99/orbex-a)

Adaptive tube model predictive control for orbital rendezvous and capture, with set-membership estimation of uncertain parameters. This simulation code builds on my M.S. research and our [2025 IEEE Aerospace Conference paper](https://doi.org/10.1109/AERO63441.2025.11068695).

The repository includes [study scripts](https://github.com/aaronjs99/orbex-a/tree/master/scripts/simulation) that save experiment inputs and source snapshots.

### [Manta-LMPC](https://github.com/aaronjs99/manta-lmpc)

A Python/CasADi simulation testbed for decentralized learning model predictive control and range-aided localization across modeled ground, surface, and underwater robots. The repository includes [plots and run records](https://github.com/aaronjs99/manta-lmpc/tree/main/results/latest) and a [resumable simulation workflow](https://github.com/aaronjs99/manta-lmpc/blob/main/docs/manta_runs.md).

### [MACRO](https://github.com/aaronjs99/macro)

Distributed allocation, formation maneuvers, and attitude coordination for spacecraft assembly in an elliptic orbit. I developed the framework during my undergraduate thesis under Dwaipayan Mukherjee's supervision and evaluated it in simulation. [2021 Indian Control Conference paper](https://doi.org/10.1109/ICC54714.2021.9703189).
